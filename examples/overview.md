# Examples overview

This section is reserved for future example specifications, thought experiments, and evaluation sketches.

The purpose of these examples is to make the SPEX research direction concrete without pretending that a finished language or runtime already exists.

Planned content includes:

- sample specification fragments
- side-by-side comparisons with generated-code workflows
- evaluation sketches for solver-guided authoring
- examples that separate functional requirements from nonfunctional requirements

For the current research framing, start with the [README](../README.md) and the [manifest](../manifest.md).
